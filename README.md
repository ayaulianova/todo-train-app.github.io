# todo-train-app.github.io 

Иерархическая структура. Приложение должно позволять создавать группы (например, «Дом», «Работа»), внутри которых находятся списки задач на конкретную тему.
Создание списков. Пользователь должен иметь возможность легко создавать новые списки, давать им понятные названия и выбирать для них цвета для визуального разделения.
Добавление и настройка задач. Каждая задача должна давать возможность указать дату, время и напоминание о её выполнении.
Подзадачи и заметки. Полезно иметь функцию разбивки большой задачи на мелкие шаги (подзадачи) и возможность оставлять к ним заметки.
Повторение задач. Приложение должно поддерживать настройку регулярного повторения задач (ежедневно, еженедельно и т.д.).
Отслеживание прогресса. Возможность отмечать задачи как выполненные и удобный поиск по ним.
Офлайн-работа. Важным плюсом является возможность работать с задачами без подключения к интернету.
Интерфейс и удобство. В приложении должны быть удобные разделы на главном экране, например, «Сегодня» (задачи с дедлайном на сегодня) и «Планирование» (полный список всех задач). Также приветствуются тёмная и светлая темы оформления, поддержка нескольких языков.

Как это работает
В TuDu всё строится на трёх уровнях: группа → список → задача. Например, в группе «Дом» можно создать список «Покупки», а внутри него — задачи «Купить молоко», «Купить хлеб».
